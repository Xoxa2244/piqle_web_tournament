## Известные ограничения (НЕ баги — в репорт не заносить)

1. **Light Mode сломан** на большинстве страниц — глобальный известный баг, чинится отдельно. Тестируем только Dark.
2. **Preview в Audiences считает 15–25 сек** на больших клубах — известно, кандидат на оптимизацию. Баг — только если Error или >60 сек.
3. **Revenue в Programming Health — оценка** (цена × confirmed), не транзакции. Подписано в UI.
4. **No-shows нет** — CourtReserve их не отдаёт; показываются Cancellations. Подписано в UI.
5. **Медленная первая загрузка** Members / Membership Health (5–9 сек) — известная проблема, не из этого релиза.
6. «Season-to-date» из фидбека оператора = пока YTD + Custom; пер-клубный «старт сезона» — фоллоу-ап.
7. Membership-цены = «contracted» из каталога CR, не фактические платежи. Подписано в UI.
